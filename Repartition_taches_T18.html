Plan de Répartition des Tâches & Livrables

Projet T18 — HomeService : FasoSkills (Marketplace d’Artisans Locaux)
Advanced Mobile Development · Year 3 · Dr Lebian Wilfried NIKIEMA · Équipe : Cédric, Aman, Prisca, Grace
État d'avancement réel pris en compte :
  • CÉDRIC a entièrement conçu et intégré le Frontend Mobile Flutter pour l'Espace Client et l'Espace Artisan/Agent (Accueil FasoSkills avec carrousel 3 cartes, liste des professionnels avec filtres et recherche, fiche profil artisan professionnelle, formulaire « Nouvelle demande » conforme à la maquette, onglet « Discussions » avec chat en direct, écran notifications).
  • AMAN a réalisé le Frontend pour l'Administration (Dashboard web/mobile) et le Backend API exclusivement pour l'Administration (gestion des comptes, catégories, validation des badges certifiés).
  • PRISCA et GRACE complètent l'équipe pour finaliser la logique métier, les tests de conformité, la recette fonctionnelle, la documentation et le packaging des livrables finaux.
⚠️ Règle impérative de Dr Lebian Wilfried NIKIEMA (Project Book p. 3 & 16) :
« Roles are a way to share responsibility, not to split knowledge. Every member must write code in both the API and the app, and must be able to explain the whole project during the defence. A student who contributed no code, or who cannot explain any part of the project, receives an individual factor close to 0. »
Chaque membre de l'équipe possède donc des livrables de code vérifiables sur le dépôt Git (commits/PR) et un paragraphe individuel obligatoire dans le rapport final (Milestone 4).
